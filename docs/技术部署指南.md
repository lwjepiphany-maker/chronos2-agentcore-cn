# 技术部署指南：Chronos-2 销量预测 + Amazon Bedrock AgentCore（中国区，CloudFormation 版）

一个 CloudFormation 模板（`iac/template.yaml`）完成全部部署：在区域内用 CodeBuild 构建两个 arm64 镜像，创建两个 AgentCore Runtime、IAM 角色、私有数据桶，把大模型 Key 存入 AgentCore Identity，并开启 CloudWatch Transaction Search。部署机**不需要 Docker**。

```
aws cloudformation deploy
  ├─ S3 数据桶（Block Public Access + SSE，删栈时保留）
  ├─ ECR ×2（删栈时连镜像一起删）
  ├─ Secrets Manager：大模型 Key（仅 CodeBuild 可读）
  ├─ CodeBuild（原生 arm64）：取源码 → 下载权重 → 构建推送镜像 → 写 Identity → 开 Transaction Search → 回调 CloudFormation
  ├─ Lambda：启动 CodeBuild 并传入回调地址
  └─ AWS::BedrockAgentCore::Runtime ×2（预测服务 MCP / Agent HTTP），IAM 鉴权
```

## 一、前提条件

| 项目 | 要求 |
|---|---|
| AWS 账号 | 中国区（宁夏 cn-northwest-1 / 北京 cn-north-1），已开通 Bedrock AgentCore |
| 部署机权限 | CloudFormation、IAM（建角色）、ECR、S3、CodeBuild、Lambda、Secrets Manager、bedrock-agentcore-control |
| 本机工具 | AWS CLI v2（最新版）、Python 3.10+（`pip install -i https://mirrors.aliyun.com/pypi/simple pandas pyarrow openpyxl boto3`，用于数据转换和测试） |
| 源码来源 | 二选一：GitHub 仓库地址（CodeBuild 需能访问 github.com），或把仓库打成 zip 放到本账号 S3（离线交付） |
| 模型权重 | 默认 CodeBuild 从 ModelScope 直链下载（约 480 MB，境内）；也可放 GitHub Release 并传 `WEIGHTS_URL` |
| 大模型 | 任一 OpenAI 兼容接口 + API Key（已验证 PPIO 的 `deepseek/deepseek-v4-flash-0731`） |

## 二、部署步骤

```bash
# 1. 销售数据 Excel → parquet（列：date, store, store_type, sku, qty, weather, temp_low, temp_high, weekday）
python iac/prepare_data.py 门店销售数据.xlsx data/sales_daily.parquet

# 2. 一键部署（首次约 25~30 分钟，主要是镜像构建）
LLM_API_KEY='sk_xxx' bash iac/deploy.sh https://github.com/<you>/chronos2-agentcore-cn.git data/sales_daily.parquet
#    离线交付：zip -r src.zip . -x '.git/*'；aws s3 cp src.zip s3://<桶>/src.zip；第一个参数改为 s3://<桶>/src.zip

# 3. 验证
python tests/bench.py --runtime-arn <ChronosRuntimeArn> --repeat 2
python tests/agent_cloud_test2.py <AgentRuntimeArn>
```

`deploy.sh` 可选环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `AWS_REGION` | cn-northwest-1 | 区域 |
| `PREFIX` | chronos2 | Runtime 名前缀（`<prefix>_forecast` / `<prefix>_agent`）和桶名前缀，小写字母数字 |
| `IMAGE_TAG` | v1 | 改动后重新执行即重建镜像并滚动升级两个 Runtime |
| `WEIGHTS_URL` | ModelScope 直链 | 权重文件所在目录地址 |
| `STORE_CITY` | 西安 | 门店城市，天气 MCP 用 |
| `LLM_BASE_URL` / `LLM_MODEL` | PPIO / DeepSeek V4 Flash | 任何 OpenAI 兼容接口 |
| `IDLE_TIMEOUT` | 600 | 会话空闲多少秒释放（主要成本开关） |
| `GITHUB_TOKEN` | — | 私有仓库 |

直接用 CloudFormation 也可以：`aws cloudformation deploy --template-file iac/template.yaml --stack-name chronos2-agentcore --capabilities CAPABILITY_NAMED_IAM --parameter-overrides ...`，参数名见模板 `Parameters`。

## 三、栈输出与调用方式

| 输出 | 用途 |
|---|---|
| `ChronosRuntimeArn` | 预测服务，供 AI 助手直连或 Agent 调用 |
| `AgentRuntimeArn` | 补货助手 Agent，业务系统 / 前端调用 |
| `DataBucket` | `data/sales_daily.parquet` 放销售历史；`charts/` 存 Agent 画的图 |
| `McpProxyCommand` | 复制即可在 Claude Code 注册预测服务 |

**前端（本机或内网）**：

```bash
pip install -i https://mirrors.aliyun.com/pypi/simple -r frontend/requirements.txt
streamlit run frontend/app.py -- --agent-arn <AgentRuntimeArn> --data-bucket <DataBucket> --region cn-northwest-1
```

前端使用者的 IAM 需要：`bedrock-agentcore:InvokeAgentRuntime` 与 `bedrock-agentcore:StopRuntimeSession`（Agent ARN 及 `/*`）、数据桶 `data/*` 的 `s3:PutObject`（上传 Excel）、`charts/*` 与 `reports/*` 的 `s3:GetObject`、`xray:BatchGetTraces`（查看调用链瀑布图）；可选 `bedrock-agentcore:GetAgentRuntime`（侧栏显示大模型名）。

**业务系统调用（Python）**：

```python
import boto3, json
rt = boto3.client("bedrock-agentcore", region_name="cn-northwest-1")
r = rt.invoke_agent_runtime(
    agentRuntimeArn="<AgentRuntimeArn>", qualifier="DEFAULT",
    runtimeSessionId=session_id,     # 同一会话复用，Agent 记住上下文；至少 33 个字符
    runtimeUserId=user_id,           # 必填，否则 Agent 取不到大模型 Key
    contentType="application/json", accept="application/json",
    payload=json.dumps({"prompt": "预测5号店商品12080084下周销量"}).encode())
print(json.loads(r["response"].read())["result"])
```

调用方 IAM：对 Runtime ARN 及 `ARN/*` 的 `bedrock-agentcore:InvokeAgentRuntime`；前端还需数据桶 `charts/*` 的 `s3:GetObject`。

## 四、日常运维

| 操作 | 方法 |
|---|---|
| 更新销售数据 | 前端侧栏上传 Excel（推荐，需启动时带 `--data-bucket`），或 `prepare_data.py` + `aws s3 cp` 到 `s3://<DataBucket>/data/sales_daily.parquet`；Agent 按 ETag 30 秒内热加载，数据桶有版本控制可回退 |
| 更新代码 / 模型 | 改 `IMAGE_TAG` 重跑 `deploy.sh`（或 `cloudformation deploy`），约 15 分钟；Runtime 保留旧版本可回滚 |
| 轮换大模型 Key | 换 `LLM_API_KEY` 重跑 `deploy.sh`，CodeBuild 会更新 Identity 里的 Key |
| 看日志 | CloudWatch 日志组 `/aws/bedrock-agentcore/runtimes/<runtime-id>-DEFAULT`；构建日志 `/aws/codebuild/<栈名>-image-build` |
| 批量预测 | 对话中让 Agent 调 `forecast_top_skus`，或定时跑 `tools/batch_forecast.py`，报表在 `s3://<DataBucket>/reports/` |
| 看调用链 | CloudWatch → Transaction Search / X-Ray，按 `service.name=<prefix>_agent` 过滤 |
| 看用量 | CloudWatch 指标 `AWS/Bedrock-AgentCore`：`CPUUsed-vCPUHours`、`MemoryUsed-GBHours`、`Sessions` |
| 删除 | `aws cloudformation delete-stack --stack-name <栈名>`；数据桶保留，确认不需要后 `aws s3 rb s3://<DataBucket> --force` |

## 五、排障

| 现象 | 原因 / 处理 |
|---|---|
| 栈创建失败，`ImageBuild` 报 `build failed, see CodeBuild ...` | 看 `/aws/codebuild/<栈名>-image-build` 日志。常见：源码地址不可达、权重下载失败（文件 < 400 MB 会主动报错）、公网拉取基础镜像 / torch 超时 → 重试 |
| 栈创建卡在 `ImageBuild` 超过 50 分钟 | CodeBuild 超时（50 分钟）；栈会在 1 小时后超时回滚。删栈后重试 |
| 删栈失败：桶非空 | 数据桶是 Retain，不会阻塞；若报 ECR 非空，模板已设 `EmptyOnDelete`，重试删栈 |
| Agent 报 `GetResourceApiKey` AccessDenied | 调用时没传 `runtimeUserId` |
| Agent 报找不到数据 | `data/sales_daily.parquet` 未上传，或列名不符（用 `prepare_data.py` 生成） |
| 带天气预测报错 | Runtime 需能出站访问 api.open-meteo.com；VPC 模式需 NAT |

## 六、中国区注意事项

1. Runtime 入站鉴权只有 IAM 和非 Cognito 的 OIDC（CUSTOM_JWT）；宁夏没有 Cognito。
2. 没有 AgentCore Memory，跨会话记忆需自行存 DynamoDB。
3. 中国区无 Bedrock 基础模型，用国产模型 API；对话内容会发给模型服务商，需评估合规。
4. CodeBuild 构建时访问 public.ecr.aws、download.pytorch.org、清华 PyPI 镜像、ModelScope；镜像约 800 MB + 200 MB。
5. 所有资源默认不对公网暴露；要做公网 Web 入口需 ICP 备案并先完成用户登录（OIDC）。
